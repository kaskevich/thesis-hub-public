# Changelog

## 1.0 (5 October 2026)

First release.

- Layers: coastal zone and regions; GI raster (MSPA input) and GI class raster; MSPA raster; tree cover loss
  and imperviousness increase rasters; roads crossing GI; hexagon layers with indicators, cumulative impact
  and hot-spot classes.
- Tables: Table 3 and Table 4 sources, element areas by county and GI class, Annex I habitats by element,
  landscape metrics (patch and landscape level).
- Code: original R and Python scripts; reproduction scripts; build script.
- Documentation: data dictionary, MSPA codes, methods and parameters, provenance and licences, comparison of
  165 published values with the data.

Not included yet: GI polygons with Annex I codes, MSPA element polygons, grassland abandonment polygons and
raster. They will be added once the redistribution terms of the habitat inventory are confirmed.
