# Data releases · Volha Kaskevich

Source of <https://kaskevich.github.io/thesis-hub-public/>.

## Paper I data release, version 1.0

`paper1-data/` holds the data and code behind:

Kaskevich, V., Villoslada, M., Ward, R.D., Sepp, K. (2024). Analyzing the structural
elements, ecological characteristics, and impact assessment of local green infrastructure
in the coastal zone of Estonia. *Ecological Indicators* 169, 112824.
<https://doi.org/10.1016/j.ecolind.2024.112824>

| Path | Contents |
|---|---|
| `paper1-data/index.html` | Overview, file list, comparison with the article, citation |
| `paper1-data/map.html` | Map viewer for the layers |
| `paper1-data/browse.html` | File browser with a preview of every file |
| `paper1-data/files/` | The data package (a file over 25 MB is provided as a zip) |
